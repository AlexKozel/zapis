# Запись клиентов для мастеров

Спецификация: [docs/spec.md](docs/spec.md).

Офлайн-календарь мастера: запись без накладок, база клиентов, напоминания, итоги. Работает без интернета и синхронизируется, когда связь появляется.

## Структура

| Папка | Что внутри | Статус |
| --- | --- | --- |
| `packages/core` | Логика календаря, статистики, синхронизации и тексты сообщений. Общая для телефона и сервера. | готово, 33 теста проходят |
| `packages/server` | Fastify, PostgreSQL (Prisma), Telegram-бот на grammY. | схема базы готова, API — неделя 3 |
| `packages/app` | Приложение мастера: React, Vite, PWA, локальная база Dexie. | Календарь, Новая запись, Клиенты (с импортом CSV и vCard), Услуги, Настройки; работает без сервера и без сети; русский и польский интерфейс |

## Что умеет ядро (`packages/core`)

- `checkBooking` — проверка накладок с учётом запаса после услуги; накладка блокирует сохранение, пока мастер не выберет «поставить параллельно».
- `freeSlots` — свободные окна на день для услуги нужной длины, с перерывами и без прошедшего времени.
- `applyDelay` — «задерживаюсь на N минут»: какие следующие записи сдвинуть и на сколько, по цепочке.
- `clientStats` — визиты, сумма, средний интервал между визитами, следующий визит.
- `incomeSummary` — доход, визиты, неявки и отмены за период.
- `mergeById` — слияние данных телефона и сервера: побеждает последнее изменение, затёртая версия уходит в историю.
- `reminderText`, `delayText`, `shareLink`, `chatLink` — напоминания и сообщения о задержке на русском, украинском, польском и английском; ссылки для Viber, SMS, Telegram и Instagram.
- `parseCsv`, `clientsFromTable`, `clientsFromVcf`, `dedupeClients`, `normalizePhone` — импорт клиентов из CSV (в том числе Excel в cp1251) и контактов iPhone, телефоны Беларуси и Польши, без дублей.
- `freeWindows` — свободные промежутки рабочего дня для подсветки в календаре.

## Запуск

Нужен Node.js 22.18 или новее (запускает TypeScript без сборки).

```bash
cd packages/core
node --test test/*.test.ts      # тесты, внешние пакеты не нужны
npm install && npm run typecheck
```

Приложение (из корня репозитория):

```bash
npm install
npm run dev        # http://localhost:5173, в локальной сети — по адресу, который покажет Vite
npm run build      # сборка с service worker в packages/app/dist
```

При первом запуске создаются стартовые услуги и рабочие часы пн–сб 9:00–19:00; их меняют на экранах «Услуги» и «Настройки». Изменения копятся в локальной очереди `outbox` и уйдут на сервер, когда появится синхронизация.

### Хостинг приложения

Приложение — статические файлы, нужен только HTTPS (без него iPhone не установит его и не будет работать офлайн). Cloudflare Pages, проект из этого репозитория:

- Build command: `npm run build -w packages/app`
- Build output directory: `packages/app/dist`
- Root directory: корень репозитория; переменная окружения `NODE_VERSION=22`

### Установка на iPhone

Открыть адрес в **Safari** → «Поделиться» → «На экран „Домой“». Один раз открыть при связи, дальше работает без интернета. Данные хранятся внутри установленного приложения: удаление иконки стирает их, поэтому до синхронизации (неделя 3) — «Настройки → Сохранить копию» хотя бы раз в неделю.

Сервер (когда будет API):

```bash
cd packages/server
npm install
DATABASE_URL=postgresql://... npx prisma migrate dev
npm run dev
```

## Решения

- Время хранится в epoch-миллисекундах UTC, деньги — в копейках или грошах целыми числами.
- Id создаются на телефоне (UUID), чтобы записи можно было создавать без связи.
- Удаление мягкое (`deleted: true`), чтобы оно тоже синхронизировалось.
- Для гибкой услуги свободные окна ищутся по максимальной длительности: лучше лишний запас, чем накладка.
- Тексты интерфейса — в `packages/app/src/i18n` (русский основной, польский обязан повторять его структуру). Язык, валюта и страна для телефонов — в настройках, не в коде.
- Восстановление из копии работает как синхронизация: побеждает последнее изменение, более новые данные телефона не затираются.
