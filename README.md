# Запись клиентов для мастеров

Спецификация: [docs/spec.md](docs/spec.md).

Офлайн-календарь мастера: запись без накладок, база клиентов, напоминания, итоги. Работает без интернета и синхронизируется, когда связь появляется.

## Структура

| Папка | Что внутри | Статус |
| --- | --- | --- |
| `packages/core` | Логика календаря, статистики, синхронизации и тексты сообщений. Общая для телефона и сервера. | готово, 19 тестов проходят |
| `packages/server` | Fastify, PostgreSQL (Prisma), Telegram-бот на grammY. | схема базы готова, API — неделя 3 |
| `packages/app` | Приложение мастера: React, Vite, PWA, локальная база Dexie. | зависимости описаны, экраны — неделя 1–2 |

## Что умеет ядро (`packages/core`)

- `checkBooking` — проверка накладок с учётом запаса после услуги; накладка блокирует сохранение, пока мастер не выберет «поставить параллельно».
- `freeSlots` — свободные окна на день для услуги нужной длины, с перерывами и без прошедшего времени.
- `applyDelay` — «задерживаюсь на N минут»: какие следующие записи сдвинуть и на сколько, по цепочке.
- `clientStats` — визиты, сумма, средний интервал между визитами, следующий визит.
- `incomeSummary` — доход, визиты, неявки и отмены за период.
- `mergeById` — слияние данных телефона и сервера: побеждает последнее изменение, затёртая версия уходит в историю.
- `reminderText`, `delayText`, `shareLink` — напоминания и сообщения о задержке на русском, украинском, польском и английском; ссылки для Viber и SMS.

## Запуск

Нужен Node.js 22.18 или новее (запускает TypeScript без сборки).

```bash
cd packages/core
node --test test/*.test.ts      # тесты, внешние пакеты не нужны
npm install && npm run typecheck
```

Сервер (когда будет API):

```bash
cd packages/server
npm install
DATABASE_URL=postgresql://... npx prisma migrate dev
npm run dev
```

## Решения

- Время хранится в epoch-миллисекундах UTC, деньги — в копейках или грошах целыми числами.
- Id создаются на телефоне (UUID), чтобы записи можно было создавать без связи.
- Удаление мягкое (`deleted: true`), чтобы оно тоже синхронизировалось.
- Для гибкой услуги свободные окна ищутся по максимальной длительности: лучше лишний запас, чем накладка.
