# Публикация приложения на Cloudflare Pages

Приложение — статические файлы, нужен только хостинг с HTTPS: без него iPhone не установит приложение на экран «Домой» и оно не будет работать без интернета. Cloudflare Pages бесплатен, в том числе для коммерческих проектов. Домен не нужен: будет адрес вида `zapis.pages.dev`.

## 1. Отправить код на GitHub

Cloudflare собирает приложение прямо из репозитория `AlexKozel/zapis`. Ветки с работой пока есть только на компьютере:

```bash
git push -u origin week1-app week2
```

## 2. Создать проект в Cloudflare

1. Зарегистрироваться на [dash.cloudflare.com](https://dash.cloudflare.com) (бесплатный тариф).
2. Слева **Workers & Pages** → **Create** → вкладка **Pages** → **Connect to Git**.

   Если Cloudflare предлагает только Workers, ищите на той же странице ссылку на Pages, например «Looking to deploy Pages? Get started».
3. Разрешить Cloudflare доступ к GitHub. Достаточно доступа к одному репозиторию `zapis`.
4. Выбрать репозиторий `zapis` → **Begin setup**.

## 3. Настройки сборки

| Поле | Значение |
| --- | --- |
| Project name | `zapis` (станет адресом `zapis.pages.dev`; если имя занято, Cloudflare предложит другое) |
| Production branch | `main` |
| Framework preset | `None` |
| Build command | `npm run build -w packages/app` |
| Build output directory | `packages/app/dist` |
| Root directory | пусто (корень репозитория) |
| Environment variables | `NODE_VERSION` = `22` |

**Save and Deploy.** Первая сборка идёт 1–3 минуты. Если в логе ошибка, пришлите её мне.

## 4. Какой адрес открывать

- `main` → `https://zapis.pages.dev`. Это рабочая версия для Кристины.
- Любая другая ветка собирается отдельно, например `https://week2.zapis.pages.dev`. Это удобно, чтобы проверить новое, не трогая её версию.

Пока `week2` не слита в `main`, на основном адресе ничего нет. Для показа есть два пути:
- открыть адрес ветки `week2`;
- или слить ветку в `main`: `git checkout main && git merge week2 && git push`.

## 5. Установить на iPhone

1. Открыть адрес в **Safari**. В других браузерах на iPhone это меню может отсутствовать.
2. «Поделиться» → **«На экран „Домой“»** → «Добавить».
3. Запустить с иконки и один раз открыть все вкладки, пока есть интернет.

## 6. Что проверить на iPhone перед показом

- [ ] Иконка на экране «Домой», приложение открывается без адресной строки Safari.
- [ ] Авиарежим → приложение открывается, записи видны, новая запись сохраняется, сверху плашка «Нет связи».
- [ ] «Настройки → Сохранить копию» → копия сохраняется в «Файлы».
- [ ] Карточка клиента → «В контакты телефона» → открывается карточка с «Создать новый контакт».
- [ ] «Клиенты → Импорт» → выбрать .vcf из «Файлов».

## Обновления

Каждый `git push` пересобирает сайт сам. Установленное приложение подтягивает новую версию при следующем запуске со связью. Данные на телефоне при этом не трогаются: они хранятся отдельно от файлов приложения.

## Открыт ли адрес в Беларуси

Адреса `*.pages.dev` иногда блокируют в отдельных странах. До показа откройте адрес с белорусского мобильного интернета без VPN. Если не открывается, решение — свой домен, подключается в Cloudflare за несколько минут.
