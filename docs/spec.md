# Спецификация MVP (кратко)

Полная версия: https://claude.ai/artifact/3s9DAF5U8CQNbRWoAvQC5c

## Цель беты
Надёжный календарь мастера, который работает без интернета и не допускает накладок. Бета-тестер — парикмахер (сложное окрашивание, 45–55 записей в месяц, 200+ клиентов). Успех: к 20 декабря вся запись ведётся в приложении, блокнот не нужен.

## Функции
| Функция | Приоритет |
| --- | --- |
| Календарь дня и недели | P1 |
| Защита от накладок, с осознанной «параллельной» записью | P1 |
| Услуги с гибкой длительностью, запас после услуги, услуга «консультация» | P1 |
| Работа без интернета (IndexedDB, PWA) и синхронизация | P1 |
| База клиентов: история, частота, сумма | P1 |
| Быстрое добавление записи (3 нажатия) | P1 |
| Вечерняя сводка мастеру в Telegram | P1 |
| Импорт клиентов (CSV, контакты) | P1 |
| Напоминание клиенту накануне (Telegram, текст для Viber/SMS) | P2 |
| Кнопка «задерживаюсь» с сообщением следующему клиенту | P2 |
| Итоги доходов за день, неделю, месяц | P2 |
| Страница онлайн-записи для Instagram/Telegram | P3 |
| Предоплата BLIK и картой (только ЕС) | P3 |

Не входит: склад, салоны с несколькими мастерами, рекламные рассылки, каталог мастеров.

## Экраны
Сегодня · Календарь · Новая запись · Клиенты · Услуги · Итоги.

## Офлайн
Телефон — главная копия данных. Каждое изменение пишется локально и ставится в очередь на отправку. Конфликты: побеждает последнее изменение (`updatedAt`), затёртая версия сохраняется в истории. Удаление мягкое.
