# Спецификация MVP (кратко)

Полная версия: https://claude.ai/artifact/3s9DAF5U8CQNbRWoAvQC5c

## Цель беты
Надёжный календарь мастера, который работает без интернета и не допускает накладок. Бета-тестер — парикмахер в Беларуси (сложное окрашивание, 45–55 записей в месяц, 200+ клиентов). Успех: к 20 декабря вся запись ведётся в приложении, блокнот не нужен.

## Функции
| Функция | Приоритет |
| --- | --- |
| Календарь дня, недели и месяца | P1 |
| Защита от накладок, с осознанной «параллельной» записью | P1 |
| Услуги с гибкой длительностью, запас после услуги, услуга «консультация» | P1 |
| Работа без интернета (IndexedDB, PWA) и синхронизация | P1 |
| База клиентов: история, частота, сумма | P1 |
| Быстрое добавление записи (3 нажатия) | P1 |
| Вечерняя сводка мастеру в Telegram | P1 |
| Импорт клиентов (CSV, контакты iPhone в .vcf) | P1 |
| Напоминания клиенту накануне и за 2 часа: Telegram-ботом (если клиент его запустил) или готовый текст в буфер обмена + открыть чат в Telegram/Instagram | P2 |
| Кнопка «задерживаюсь» с сообщением следующему клиенту | P2 |
| Итоги доходов за день, неделю, месяц | P2 |
| Заявка на запись по ссылке (Instagram/Telegram): клиент оставляет услугу и удобные дни, мастер назначает время и длительность | P3 |
| Предоплата BLIK и картой (только ЕС) | P3 |

**Принцип:** время и длительность записи всегда назначает мастер; клиент не бронирует слот сам. Самозапись — возможная опция позже для простых услуг, по умолчанию выключена.

Не входит: склад, салоны с несколькими мастерами, рекламные рассылки, каталог мастеров.

## Экраны
Сегодня · Календарь · Новая запись · Клиенты · Услуги · Итоги.

## Офлайн
Телефон — главная копия данных. Каждое изменение пишется локально и ставится в очередь на отправку. Конфликты: побеждает последнее изменение (`updatedAt`), затёртая версия сохраняется в истории. Удаление мягкое.

Онлайн-запись клиента сервер подтверждает сразу, только если телефон мастера синхронизировался за последние 15 минут; иначе запись «ожидает подтверждения», и приложение мастера подтверждает её само после проверки накладок, когда появится связь. Поэтому у записи есть статус «ожидает подтверждения» и источник (мастер, онлайн-запись, бот), а синхронизация принимает записи, созданные на сервере.
